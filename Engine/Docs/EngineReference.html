はじめに

ゲームは「Framework を継承したアプリクラス」と「BaseScene を継承したシーン」で書きます。Game ブランチの最小構成は次のとおりです。

Game/main.cpp ・ Game/MyGame.cpp

int WINAPI WinMain(_In_ HINSTANCE, _In_opt_ HINSTANCE, _In_ LPSTR, _In_ int) {
    MyGame game;
    game.Run();   // 初期化 → メインループ → 終了処理
    return 0;
}

// MyGame は Engine::Framework を継承し、Initialize だけをオーバーライドする
void MyGame::Initialize() {
    SetWindowTitle(L"My Game");   // Framework::Initialize より前に呼ぶと最初からこのタイトルで開く
    Framework::Initialize();      // エンジン各機能の初期化
    ChangeScene<TitleScene>();    // 最初のシーンを予約する
}

Game/Scene/TitleScene.h ・ .cpp

#include "Engine/Rendering/Object3D.h"
#include "Engine/Scene/BaseScene.h"

class TitleScene : public Engine::BaseScene {
protected:
    void OnInitialize() override;   // 開始時に1回
    void OnUpdate() override;       // 毎フレーム：処理と各オブジェクトの Update()
    void OnDraw() override;         // 毎フレーム：各オブジェクトの Draw()
private:
    Engine::Object3D logo_;
};

// ---- TitleScene.cpp ----
#include "Engine/Input/Input.h"
#include "Game/Scene/GameScene.h"
using namespace Engine;

void TitleScene::OnInitialize() {
    camera_.GetTransform().translate = { 0.0f, 0.0f, -6.0f };  // カメラを手前に引く
    logo_.Initialize(Primitive::kCube);                        // 仮モデル（白い立方体）
    logo_.SetColor({ 1.0f, 0.8f, 0.2f, 1.0f });
}

void TitleScene::OnUpdate() {
    if (Input::GetInstance()->IsTrigger(DIK_RETURN)) {
        ChangeScene<GameScene>();                              // 次のフレームの頭で切り替わる
    }
    logo_.GetTransform().rotate.y += 0.02f;
    logo_.Update();                                            // Draw より前に毎フレーム
}

void TitleScene::OnDraw() {
    logo_.Draw();
}

1フレームの流れ

Framework::Run() のメインループが毎フレーム行う処理です。色の付いた行がゲーム側のコード（シーンの On～）が呼ばれるところです。

  1. ウィンドウのメッセージを処理する（×ボタンでループを抜けて終了処理へ）
  2. ウィンドウサイズが変わっていれば、スワップチェーンや深度バッファを作り直す
  3. 予約されたシーンがあれば切り替える（GPUの完了待ち → 前のシーンを破棄 → 次のシーンの OnInitialize）SceneManager
  4. [Debug] ImGui のフレームを始め、DrawImGui（シーンの OnDrawImGui）で UI を組み立てる
  5. 入力を更新する（キーボード・マウス・パッドの今フレームの状態を取る）Input::Update
  6. F11 が押されたらボーダレス全画面を切り替える
  7. ゲームの描画先矩形をシーンへ渡す（Debug では ImGui のドッキングで空いた中央領域）
  8. Update → シーンの OnUpdate → カメラの確定（ビュー・射影・視錐台）→ 光源を定数バッファへ
  9. 画面をクリアする（BeginFrame）→ PreDraw フック
  10. Draw → ルートシグネチャ・カメラ・光源・標準PSOを設定 → シーンの OnDraw → DebugDraw の線
  11. [Debug] ImGui を画面全体へ描く
  12. 画面に表示する（EndFrame。垂直同期あり）→ このフレームの DebugDraw の線を消す
  13. 1/60 秒が経つまで待ち、次のフレームの経過時間を確定するTime::WaitForNextFrame
順番のポイント OnDrawImGui は同じフレームの OnUpdate より先に呼ばれます（入力の更新よりも前）。ImGui で変えた値はそのフレームの OnUpdate と描画に反映されますが、OnDrawImGui の中で Input を読むと前のフレームの状態になります。

決まりごと

座標・行列・単位の約束です。自分で計算するときはこれに合わせます。

座標系
左手系。+X が右、+Y が上、+Z が奥（画面の向こう）。カメラは既定で原点から +Z を向く。
角度
すべてラジアン。Transform3D::rotate は X → Y → Z の順に回す。カメラの rotate.x を正にすると下を向き、rotate.y を正にすると右を向く。
行列
行優先・行ベクトル（v * M）。合成は左から右：world = S * R * T、WVP = world * view * proj。平行移動は m[3][0..2]。
深度
DirectX の規約で 0（手前）〜 1（奥）。
大きさ
長さの単位は自由。組み込みの形状（Primitive）は1辺・直径が 1。
色
Vector4 の RGBA、各 0.0〜1.0。16進数 0xRRGGBBAA（8桁）でも指定できる。色を持つものはどれも SetColor で設定する。→ ColorFromHex
時間
更新は毎秒 60 回に固定。「1フレームあたりの量」で書いてよい。秒単位なら Time::GetDeltaTime() を掛ける。
2D座標
スプライトとマウスは左上原点・ピクセル・+Y が下。スプライトは 1280×720 を基準に指定する。
画面
最初は 1280×720（WinApp::kClientWidth/Height）。ウィンドウはサイズ変更でき、F11 で全画面。
背景色
RGB (0.1, 0.25, 0.5) で画面をクリアする。変える関数は無い（DirectXCore.cpp の clearColor で固定）。このページのアクセント色もこの色。

ビルド構成

構成定義される記号ImGuiDebugCamera用途
Debug_DEBUG, USE_IMGUIありありふだんの開発
Development_DEBUGなしありImGui を抜いた見た目の確認（最適化なし・assert 有効）

  • 全構成で警告レベル4・警告はエラー扱い。使っていない変数や引数があるとビルドが止まる（引数名を消す、[[maybe_unused]] を付ける、など）。

つまずきやすい点

エンジンの実装から分かる、ハマりやすいところです。

描画

  • Update() を呼ばないと反映されない。Object3D と Sprite は OnUpdate で Update()、OnDraw で Draw() の両方が必要です。Transform や色を変えても、次の Update() までは画面に出ません。
  • OnDraw でゲームの状態を変えない。立体視が有効なときは OnDraw が視点の数だけ（2〜8回）呼ばれます。移動や当たり判定は OnUpdate に書きます。
  • Initialize 済みの Object3D / Sprite をコピーして両方使わない。コピーは定数バッファを共有するため、両方が同じ位置・色で描かれます。複数体を出すときは1体ずつ Initialize します（std::vector<Object3D> に入れてから各要素を Initialize するのは問題ありません）。
  • 半透明は描く順番が大事。アルファブレンドは有効ですが深度も書き込むので、半透明の物は不透明な物をすべて描いた後に、奥から手前の順で描きます。
  • テクスチャのアルファが 0.8 未満のピクセルは描かれない（シェーダーで切り抜き）。フェンスのような抜きは簡単ですが、ぼかした半透明の縁は欠けます。全体を薄くしたいときはテクスチャではなく SetColor のアルファを使います。
  • スプライトは OnDraw の最後に描く。スプライトは深度 0 で書かれるので、3D より常に手前に表示されます。先に描くと、スプライトの半透明部分の下に後から描いた 3D が見えなくなります。
  • Primitive::kPlane は上からしか見えない。裏面カリングがあるので、下から見ると消えます。
  • 遠くの物が消える。カメラの描画距離は既定で 100 まで。広いステージでは camera_.SetClipPlanes(0.1f, 500.0f) などで伸ばします。
  • テクスチャは 120 枚弱まで。SRV ヒープが 128 枠で、ImGui と立体視も使います。読み込んだテクスチャはアプリ終了まで解放されません（同じパスはキャッシュされるので、何度 Load しても増えません）。

リソース

  • ファイルが見つからないと assert で止まる。パスは Game/ からの相対パスです（"resources/..."）。止まったら綴りと、ファイルが Game/resources/ にあるかを確認します。
  • OBJ は三角面にして書き出す。四角形以上の面は読み込めません（Blender の OBJ 書き出しでは三角形化（Triangulate）の設定を ON）。mtl はOBJと同じフォルダに置き、map_Kd の画像パスもそのフォルダからの相対パスにします。
  • サウンドはシーンを切り替えても解放されない。LoadWave にはキャッシュが無く、呼ぶたびに新しく読み込みます。シーンの OnInitialize で毎回読むと、シーンを行き来するたびに増えていきます。アプリ全体で1回だけ読むようにします。
  • 音はループ・停止ができない。今ある関数は LoadWave・Play・SetVolume だけです。BGM のループが必要ならエンジン側に機能を足します。

入力・その他

  • F11 はエンジンが使う（全画面の切り替え）。DebugCamera を使うシーンでは Enter もデバッグカメラの ON/OFF に使われます。
  • スティックは上が +Y、マウスは下が +Y。
  • ウィンドウが後ろにあるとキーボードとマウスは取れない（DirectInput の前面モード）。パッドは取れます。
  • OnUpdate の中の GetViewMatrix() は前のフレームの値。カメラはOnUpdate の後に確定します。
  • ImGui のコードは Debug 構成にしか無い。ImGui:: を使う行は必ず #ifdef USE_IMGUI の中に書きます（Release でビルドエラーになります）。

アプリとシーン

アプリの骨組みと、シーンの作り方・切り替え方です。

Framework

Engine/Core/Framework.h継承して使う

アプリ全体の骨組みです。ゲーム側はこれを継承したクラス（Game の MyGame）を1つ作り、WinMain で Run() を呼びます。Initialize でタイトルと最初のシーンを決めるだけで動きます。シーンの更新と描画は、既定で SceneManager に任されます。

void Run();
初期化 → メインループ → 終了処理をまとめて行います。ウィンドウが閉じられるまで戻りません。WinMain から1回だけ呼びます。
protected: virtual void Initialize();

エンジンの各機能を初期化します。順番は COM → クラッシュダンプ → ログ → Time → ウィンドウ → DirectX → シェーダー → パイプライン → DebugDraw → テクスチャ → 立体視 → Audio → Input → ImGui です。

オーバーライドするときは SetWindowTitle → Framework::Initialize() → ChangeScene<最初のシーン>() の順に書きます。

protected: virtual void Finalize();
シーンを破棄し、エンジンの各機能を生成と逆の順に解放して、解放漏れ（リソースリーク）を出力ウィンドウに報告します。オーバーライドするなら、自分のリソースを解放してから最後に Framework::Finalize() を呼びます。
protected: virtual void Update();
毎フレームの更新です。既定では現在のシーンを更新します（SceneManager::Update）。全シーン共通の処理を足すときはオーバーライドし、最後に Framework::Update() を呼びます。
protected: virtual void Draw(ID3D12GraphicsCommandList* commandList, uint32_t viewIndex);
描画コマンドを積みます。既定では現在のシーンを描画します。
commandList
描画コマンドを積むコマンドリスト
viewIndex
描画する視点の番号。立体視が OFF なら常に 0 で1回だけ呼ばれる
protected: virtual void PreDraw(ID3D12GraphicsCommandList* commandList);
画面のクリアの後、シーンの描画の前に毎フレーム呼ばれるフックです。既定では何もしません（Sandbox では Web カメラ映像の転送に使っています）。
protected: virtual void DrawImGui();Debug のみ
開発用の ImGui ウィンドウを組み立てます。既定では現在のシーンの OnDrawImGui を呼びます。全シーン共通のウィンドウを出すときにオーバーライドし、Framework::DrawImGui() も呼びます。宣言・定義とも #ifdef USE_IMGUI で囲みます。
protected: void SetWindowTitle(const std::wstring& title);
ウィンドウのタイトルを設定します。Framework::Initialize() より前に呼ぶと最初からそのタイトルで開き、後から呼ぶとその場で変わります。例: SetWindowTitle(L"My Game");
protected: template <class TScene> void ChangeScene();
次のシーンを予約します（SceneManager::GetInstance()->ChangeScene<TScene>() と同じ）。最初のシーンもこれで指定します。

BaseScene

Engine/Scene/BaseScene.h継承して使う

シーンの基底クラスです。カメラのビュー射影・視錐台・平行光源・点光源・立体視・PSO の設定といった定型処理はこのクラスが行うので、派生シーンは OnInitialize / OnUpdate / OnDraw（必要なら OnDrawImGui）を書くだけで済みます。シーンは切り替えのたびに新しく作られ、前のシーンは破棄されます。メンバー変数は毎回初期状態から始まります。

ImGui で値を調整する（Debug のみ）

// GameScene.h
#ifdef USE_IMGUI
    void OnDrawImGui() override;
#endif

// GameScene.cpp

#endif

void GameScene::OnDrawImGui() {
    ImGui::Begin("Game");
    ImGui::DragFloat3("Camera translate", &camera_.GetTransform().translate.x, 0.01f);

派生シーンが実装する関数

protected: virtual void OnInitialize() = 0;
シーンの開始時に1回呼ばれます。オブジェクトの Initialize、リソースの読み込み、カメラや光源の初期設定をここで行います。
protected: virtual void OnUpdate() = 0;
毎フレーム呼ばれます。入力・ゲームの処理・各オブジェクトの Update() を書きます。ここでカメラを動かすと、同じフレームの描画に反映されます。DebugDraw の線もここで積みます。
protected: virtual void OnDraw() = 0;
毎フレーム呼ばれます（立体視では視点の数だけ呼ばれます）。各オブジェクトの Draw() だけを書きます。標準の PSO・カメラ・光源は設定済みです。
protected: virtual void OnDrawImGui() {}Debug のみ
開発用の ImGui を組み立てます。必要なシーンだけオーバーライドします。OnUpdate より先に呼ばれます（1フレームの流れ）。
protected: virtual Matrix4x4 CalcViewMatrix() const;
描画に使うビュー行列を返します。既定は camera_.GetViewMatrix()。デバッグカメラなどで視点を差し替えるときにオーバーライドします（DebugCamera の例）。

派生シーンから使えるメンバー変数

protected: Camera camera_;
シーンのカメラ。既定は原点・回転なし（+Z 向き）・画角 0.45 rad・描画距離 0.1〜100。OnUpdate で動かすとそのフレームに反映されます。→ Camera
protected: DirectionalLight directionalLight_;
平行光源。既定は白・真下向き (0, -1, 0)・強さ 1・有効。値を変えると Update で反映されます。→ DirectionalLight
protected: PointLightGroup pointLights_;
点光源 4 個（既定はすべて OFF）。pointLights_.lights[i] を編集します。→ PointLight
protected: StereoCamera stereoCamera_;
立体視用の視点別ビュー射影。通常のゲームでは触りません。→ StereoCamera

派生シーンから使える関数

protected: template <class TScene> void ChangeScene();

Material / LightingMode

Engine/Rendering/Material.h

色と陰影の付け方です。Object3D::GetMaterial() や Sprite::GetMaterial() で取り出して編集します。シェーダー（Object3d.hlsli）と同じメモリの並びなので、メンバーの順番は変えません。
