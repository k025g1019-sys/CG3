# 操作説明
ゲーム内の操作説明はまだ未実装ですが、余裕があればゲーム内に追加しようと考えています。

## シーン切り替え
Tabキーで課題内容のシーンを切り替えられます。(Stanford_Bunnyは頂点数が他のものと比べ少し多いので、これが含まれるシーンへの遷移には若干の読み込み時間が発生します)

Tキーを押すと立方体が並んだシーンに移行します。このシーンではImGuiから変更する立体視機能をより試しやすくなっています。

## デバッグカメラ
デバッグカメラの操作説明です。
・Enterキーでデバッグカメラを有効にする
・オブジェクトにマウスカーソルを合わせ、左クリックすると、そのオブジェクトに注目する。
・マウスホイールを回すと奥行きが調整でき、押し込んで動かすと注目したオブジェクトを中心にカメラを回転できる。
・マウスの右ボタンを押したまま動かすとカメラを上下左右に平行移動できる。

## GamePad
### ✓実装できました。
操作方法です。
・Rb/LBキーでオブジェクトを選択
・左スティックを動かして選択されたオブジェクトをXZ軸に平行移動
・右スティックを動かして選択オブジェクトを回転
・RTキーで選択オブジェクトを拡大、LTキーで縮小
・Bボタンで選択オブジェクトをY軸に上昇、Aボタンで下降
・横三本線のボタンで次のシーンに遷移、四角形が2つ並んだボタンで立体視デモシーンに遷移
